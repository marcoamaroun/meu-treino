# Meu Treino 💪

App web simples para registrar treinos de academia, acompanhar a evolução das cargas e as medidas corporais.

## Funcionalidades
- Divisões de treino (A, B, C…) com exercícios, séries, repetições e carga
- Treino em andamento: marcação de séries e ajuste de carga na hora
- Cronômetro de descanso com aviso sonoro/vibração
- Exercícios sem peso
- Evolução das cargas por exercício (gráfico e histórico de sessões)
- Aba "Corpo": peso, % de gordura, circunferências e IMC

## Como usar
Abra o `index.html` no navegador (ou publique com o GitHub Pages). Os dados ficam salvos no próprio navegador (localStorage).
